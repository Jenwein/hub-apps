# Default rules

Sort each mail into one of three tiers.

## now

Mail the user should hear about at once:

- Money problems: a payment or charge failed, a card was declined, a balance is too low, or a service will stop for an unpaid bill.
- Account security: a sign-in from a new place or device, a changed password or two-step setting, or a verification code or password reset mail the user did not ask for.

## daily

Mail for the daily report:

- A person writing to the user and waiting for an answer.
- Something due within a few days: a renewal, a bill, an ID or a domain that expires.
- Order and delivery changes.
- Bills and receipts.

## ignore

Mail the user does not need to hear about:

- Marketing.
- Newsletters.
- Social network notifications.

When unsure between two tiers, take the more urgent one.
